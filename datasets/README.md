# Dataset

Không commit toàn bộ dataset Kaggle, ảnh có bản quyền, embedding hoặc FAISS index vào Git thông thường.

Repository chỉ lưu:

- Hướng dẫn tải dữ liệu.
- Phiên bản và nguồn dữ liệu.
- Quy trình tiền xử lý.
- Một fixture nhỏ hợp pháp cho test.
- Checksum của dữ liệu/artifact nếu cần tái lập.
